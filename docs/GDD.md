# 《FX战士久留美 同人 · 2000万之路》游戏设计文档（GDD）

> 原作：《FX戦士くるみちゃん》（原作 でむにゃん / 作画 炭酸だいすき，KADOKAWA）。本作为非官方同人游戏。
> 原作剧情事实以 `docs/research/manga-reference.md`（带出处的调研）为准；没有出处的情节不写进剧情模式。
> 剧情台词为改写/转述，不照搬原作对白，也不使用原作图片。

## 1. 一句话

像素风、实时可暂停的 FX（外汇）交易肉鸽：主角福賀くるみ（久留美）从 30 万円起步，目标是取回母亲亏掉的 **2000 万円**。
行情由多因子算法实时生成，新闻、经济指标、央行、自然灾害、散户情绪、朋友的博客……都会影响价格。

## 2. 模式与流程

```
标题 ─┬─ 剧情模式（跟漫画逐话走）
      │    ├─ 第 1~N 章：新手教程（交易操作逐步教学）
      │    ├─ 教程完成 → 解锁「肉鸽模式」，可继续剧情
      │    └─ 后续章节：看剧情 + 复刻漫画内经典行情战役（如 2015 瑞郎冲击）
      ├─ 肉鸽模式（教程完成后解锁）
      │    └─ 局外养成「相场勘」→ 越来越强 → 搭配构筑 → 通关 2000 万
      ├─ 经典战役（预留：剧情战役可单独重玩；以后加独立复刻战役）
      ├─ 图鉴 / 成就
      └─ 设置
```

- 剧情数据驱动：`data/story/chapters/*.json`，每章一个文件，漫画更新时新增章节文件即可（格式见 `docs/story-format.md`）。
- 通关特殊奖励（未知事件：暴涨/暴跌/特殊曲线）：预留钩子 `RunManager.on_final_clear()`，暂不实现。

目标总时长 10 小时以上：剧情（含教程与战役）约 2~3 小时；肉鸽从首局到首通依赖局外养成约 6~8 小时；之后挑战度（Ascension）与图鉴收集提供长尾。

## 3. 行情引擎（多因子，算法生成）

时间：1 tick = 15 分钟（游戏内），一天 96 tick，周一到周五开市，周末休市（周一开盘可能跳空）。

### 3.1 货币强度模型
每种货币 i 有对数强度 `x_i`，货币对价格 `P(A/B) = K_AB · exp(x_A − x_B)`。因此 USD/JPY、EUR/JPY 天然因共享日元而相关，不需要手工写相关矩阵。
股指（日经 225 CFD）和黄金也作为“资产”挂在同一套因子上。

每 tick：
```
dx_i = 趋势漂移(隐马尔可夫 regime) + 利差漂移 + 均值回归(公允价值锚)
     + Σ_k β_ik · dF_k            # 公共因子：全球风险偏好 R、美元因子 D、商品因子 C
     + σ_i(t) · ε                  # GARCH 式波动聚集 × 交易时段流动性曲线 × 事件波动倍率
     + 跳跃（泊松，强度受事件影响）
     + 事件冲击（带延迟/爬升/衰减的形状函数）
     + 散户拥挤度（止损单簇 → 猎杀止损的尖刺）
     + 央行约束（下限/上限钉住、干预）
```
- **风险偏好因子 R**：OU 过程 + regime（平稳/risk-on/risk-off/恐慌）。AUD、TRY、日经为正 β，JPY、CHF、黄金为负 β。
- **趋势 regime**：每种货币 {震荡, 多头, 空头}，随机切换；趋势期动量指标有效，震荡期布林带回归有效——指标的“有用”来自真实的隐状态。
- **公允价值**：缓慢漂移的锚；萌智子的能力可以显示这条线。
- **流动性**：东京/伦敦/纽约时段曲线；早盘、周一开盘、假日、事件发布时点差扩大、滑点变大。
- **央行**：钉住（如 EUR/CHF 下限）会积累“压力值”，突破时撤销 → 巨幅跳空、流动性蒸发、止损单远离触发价成交；干预（日元急升/急贬时）。
- **确定性**：一局一个种子（`RandomNumberGenerator`），可复现。剧情战役可用**关键帧**（布朗桥逼近历史价位）+ 脚本事件来复刻真实行情。

### 3.2 事件（“多种渠道影响行情”）
| 渠道 | 例 | 表现形式 |
|---|---|---|
| 经济指标（预定） | 雇用统计、CPI、GDP、利率决议 | 经济日历（重要度★、预测值、前值）→ 发布瞬间出实际值，惊喜值×敏感度 = 跳动 |
| 央行 | 加息/降息、量宽、干预、钉住撤销 | 「速報」电视弹窗 + 图表竖线标记 |
| 自然灾害 | 地震、台风、火山、疫情 | 世界地图像素 ping + 新闻；risk-off、日元回流、数日高波动 |
| 新闻报道 | 企业/政治/地缘新闻 | 底部滚动新闻条；可信度不同 |
| 谣言/假新闻 | 「某国将退出…」 | 先推动价格，之后可能被辟谣反转 |
| 要人发言 | 央行行长讲话 | 发言气泡，方向模糊 |
| 散户 / SNS | FX 民时间线、あふぃちゃん的博客 | SNS 面板（情绪风向）；拥挤度过高 → 止损猎杀 |
| 玩家自己 | 仲间能力（博客煽动）、巨额仓位冲击 | 后期可主动影响行情 |

事件数据：`data/events/*.json`，每个事件由若干 effect 组成：
`{target: 货币/因子/资产, channel: level|drift|vol|risk|regime|peg|liquidity, magnitude, delay, ramp, duration, decay}`。

## 4. 交易规则（FX）
- 1 枚 = 1 万通货；损益统一换算成日元。
- 证拠金 = 名义金额 / 杠杆；维持率 = 净值 / 证拠金。
- ロスカット：维持率 ≤ 业者阈值时按市价强平（跳空时滑点真实发生）。
- **国内业者**：25 倍、点差窄、无零 cut → 净值为负成为借金（追証），这正是原作瑞郎冲击的残酷之处。
- **海外业者**：最高 888 倍、点差宽、零 cut（负余额清零）、可能有入金奖金/出金风险事件。
- 订单：市价、止损 SL、止盈 TP；（技能解锁）追踪止损、挂单。
- 掉期：每日纽约收盘时按利差结算；高息货币（TRY）多单拿高掉期但有长期贬值和崩盘风险。

## 5. 久留美的「メンタル」
0~100。亏损、强平、追证、坏新闻会扣；盈利、休息、道具、朋友会回。
- 低于 30 →「暴走」：画面变红，周期性弹出「衝動」卡（全力ナンピン？/ 深呼吸），选错会被迫加仓或失去止损。
- 归零 → 心が折れた，本局失败。
所以风险管理不仅是钱的问题，也是心态资源。立绘表情随损益与メンタル变化，并有台词气泡。

## 6. 肉鸽模式
### 6.1 一局的结构
- 3 幕（第一年/第二年/第三年），每幕一张分叉地图（6 层 + Boss）。
- 节点：
  - **相場**（3 个交易日，可选小目标 → 奖励 FP）
  - **荒れ相場**（精英：特殊规则，高回报，掉落稀有「手法」）
  - **事件**（文字事件，朋友登场，选项影响资金/メンタル/道具/诅咒）
  - **商店**（用 FP 买手法/道具/仲间强化，移除诅咒）
  - **休息**（アルバイト赚现金 / 睡觉回メンタル / 学习升级手法）
  - **Boss**（5 个交易日，特殊规则；结束时净值必须 ≥ 本幕目标，否则失败；可向闇金借款凑数，年利 109.5%）
- 幕目标（净资产 = 资金 − 借金）：第一幕 80 万 → 第二幕 400 万 → 第三幕 2000 万（通关）。之后可进入无尽模式（每幕目标 ×4）。
- 数值由 `tests/sim_balance` 校准：零养成的趋势机器人几乎过不了第一幕；满养成 + 完全掌握隐藏趋势、单笔风险 10% 的机器人第一幕通过率约 70%，偶尔通关——人类玩家还能利用新闻提前量、指标预感、芽吹预言、止损猎杀等机器人没用到的优势。
- 失败条件：未达 Boss 目标、借金超过上限、メンタル归零。

### 6.2 货币
- **资金（円）**：分数也是交易本金。
- **FP（FXポイント）**：交易节点按表现结算，在局内商店用。
- **相場勘**：局外养成点数，一局结束按最高资金（对数）、通过幕数、成就结算。

### 6.3 构筑（搭配）
| 系 | 思路 | 例 |
|---|---|---|
| 情报系 | 看到隐藏因子 | 经济日历、速报（新闻先于价格）、散户持仓表、止损簇显示、公允价值线、各种指标 |
| 风控系 | 少亏 | 止损零滑点、追踪止损、保险（一次亏损返还）、メンタル护盾 |
| 赌徒系 | 多赚多亏 | 杠杆×2、全力加成、ナンピン成本优惠、零 cut 一次 |
| 掉期系 | 吃利息 | 掉期×2、解锁 TRY/JPY、掉期复利 |
| 消息系 | 指标/新闻交易 | 指标值提前 1 tick、事件后开仓加成、散布消息 |
| 仲间系 | 朋友主动/被动 | 见下 |

**仲间**（随剧情解锁，最多 2 个位，局外可扩到 3）：
- 小金萌智子：显示公允价值线；主动「分析」揭示下一个指标方向（高概率），但偶尔推荐危险的满仓操作。
- 山師芽吹：主动「闇金を紹介」立即借款（高利息诅咒）；被动：高杠杆收益加成。
- 高根やす子（あふぃちゃん）：主动「ブログで煽る」推动散户情绪；被动：联盟广告收入（FP）。
（具体性格与能力以调研为准微调。）

**道具**（消耗品）：能量饮料、损切护符、父亲的存折（+300 万但重罚メンタル并附加诅咒，致敬原作）、占卜（预览明日偏向）、有给休假（跳过一天）……

**诅咒**：借金（每日利息）、罪恶感（メンタル恢复减半）、ポジポジ病（空仓扣メンタル）、睡眠不足……

**业者**（开局选择，局外解锁）：国内大手 / 海外 888 倍 / 掉期特化 / 专业账户。

### 6.4 难度曲线
- 第一幕：趋势强（trend×2.0）、regime 平均 3.5 天、灾害少；Boss「雇用统计之夜」/「日银的意外」。
- 第二幕：趋势×1.7、regime 2.8 天、谣言与猎杀止损增多；Boss「汇率干预」/「清晨的闪崩」。
- 第三幕：趋势×1.45、regime 2.2 天、高波动、灾害×1.6；最终 Boss「黑色星期四」（钉住崩溃型）/「金融危机」。
- 首通后解锁挑战度 1~10，每级叠加一个修正（点差+、目标+、本金−、消息延迟+、メンタル衰减+…）。
- 平衡以脚本模拟（简单策略机器人跑 N 局）验证：零养成时首通率应很低，满养成+合理构筑时可稳定通关。

### 6.5 局外养成「相場勘」
元手、メンタル上限、仲间位、业者解锁、情报类手法进卡池、商店折扣/刷新、アルバイト时薪、起始道具、挑战度。

## 8. 技术
- Godot 4.7（GDScript），工程根 `projects/kurumi-fx-rogue/`。
- `src/core/`：纯逻辑（行情、交易、事件、肉鸽状态），可 headless 测试。
- `src/ui/`、`src/scenes/`：界面。
- `data/`：JSON 内容（剧情、事件、道具、手法、仲间、业者、Boss、养成树）。
- `assets/`：像素素材（ComfyUI + 角色 LoRA 生成后限色像素化）、字体、音效。
- `scripts/`：资产生成、平衡模拟等工具（`.gdignore`）。
- 存档：`user://save.json`（局外养成、剧情进度、设置、统计、当前局）。
