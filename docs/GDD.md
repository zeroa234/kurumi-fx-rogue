# 《FX战士久留美 同人 · 2000万之路》游戏设计文档（GDD）

> 原作：《FX戦士くるみちゃん》（原作 でむにゃん / 作画 炭酸だいすき，KADOKAWA）。本作为非官方同人游戏。
> 原作剧情事实以 `docs/research/manga-reference.md`（带出处的调研）为准；没有出处的情节不写进剧情模式。
> 剧情台词为改写/转述，不照搬原作对白，也不使用原作图片。
>
> 本文描述**设计与当前实现**（2026-10 同步）。标「未实现」的是设计里有、代码里还没有的部分，汇总见 §9。
> 具体数值以 `data/` 为准，字段说明见 `docs/data-reference.md`。

## 1. 一句话

像素风、实时可暂停的 FX（外汇）交易肉鸽：主角福賀くるみ（久留美）从 30 万円起步，目标是取回母亲亏掉的 **2000 万円**。
行情由多因子算法实时生成，经济指标、央行、自然灾害、新闻与谣言、散户情绪、朋友的博客……都会影响价格。
（「股市」按原作题材做成 FX 为主：9 个品种 = 7 个货币对 + 日经225 CFD + 黄金。）

## 2. 模式与流程

```
标题 ─┬─ 剧情模式（跟漫画逐卷走，第1〜15章 = 原作第1〜53話）
      │    ├─ 第 1~6 章（原作第1〜10話）：新手教程
      │    ├─ 教程完成 → 解锁「肉鸽模式」「局外养成」「图鉴」，可继续剧情
      │    └─ 第 7 章起：剧情 + 复刻漫画中的经典行情（第11章 2015-01-15 瑞郎冲击）
      ├─ 肉鸽模式：3 幕 → 通关 2000 万 → 无尽 / 挑战度
      ├─ 局外养成「相場勘」
      ├─ 经典战役：重玩剧情中 battle 标记的交易场景
      ├─ 图鉴：手法 / 道具 / 事件 / Boss / 仲间
      └─ 设置
```
- 剧情数据驱动：`data/story/chapters/*.json`，漫画更新时新增章节文件即可（`docs/story-format.md`）。
- 通关特殊奖励（未知事件：暴涨/暴跌/特殊曲线）：**未实现**，`src/run/run_map.gd` 的 `_victory()` 里只有文字占位。

目标总时长 10 小时以上：剧情约 2 小时；肉鸽从首局到首通依赖局外养成；之后挑战度与图鉴收集提供长尾。

## 3. 行情引擎（`src/core/market_sim.gd`）

时间：1 tick = 15 分钟，一天 96 tick（东京 07:00 起），周一到周五开市，周末跳过（周一开盘有随机跳空）。

### 3.1 货币强度模型
每个货币/资产单元有对数强度 `x_i`；有效强度 = `x_i + Σ β_ik · F_k`；
品种价格 `P(A/B) = anchor_A/anchor_B · exp(有效强度差 + 品种偏移)`。USD/JPY 与 EUR/JPY 因共享日元天然相关，不需要相关矩阵。

每 tick：
```
dx_i = 趋势漂移(隐马尔可夫 regime: 震荡/多头/空头) + 长期漂移(carry) + 均值回归(公允价值锚)
     + σ_i · 时段流动性曲线 · 事件波动倍率 · GARCH 状态 · ε
     + 自发跳跃（泊松）+ 事件冲击（延迟/爬升/回吐的形状函数）
dF_k = OU 过程（风险偏好 R、美元 D、商品 C）+ 事件冲击
品种层：散户多空比（逆张り倾向）→ 止损簇 → 价格接近时概率性「猎杀止损」尖刺
约束：汇率下限（钉住，积累压力；撤销时一次性释放）、日元干预（3 天内日元升/贬超 4~4.5% 时有概率出手）
```
- β：AUD、TRY、日经对风险偏好为正；JPY、CHF、黄金为负。灾害/恐慌新闻通过压低 R 产生 risk-off。
- 趋势 regime 是指标「有用」的来源：趋势期均线有效，震荡期布林带回归有效；「趋势水晶」手法可直接看到 regime。
- 公允价值：缓慢漂移的锚（萌智子显示的虚线）。
- 流动性：东京/伦敦/纽约时段曲线；换日前后、指标发布、新闻、钉住撤销时点差扩大、滑点变大。
- 确定性：同一种子行情完全一致。剧情复刻用关键帧 `guide`（布朗桥）逼近核实过的历史价位。

### 3.2 影响行情的渠道（`src/core/event_engine.gd`，数据 `data/events/`）
| 渠道 | 例 | 表现 |
|---|---|---|
| 经济指标（预定） | 非农、CPI、GDP、各央行利率决议 | 经济日历（★、预测、前值、可选「预感」）→ 发布瞬间出实际值，冲击 = 敏感度 × 惊喜值；发布前点差扩大、自动暂停 |
| 央行意外 | 紧急降息、QE、钉住撤销、日元干预 | 「速報」弹窗、图表竖线标记、屏幕震动 |
| 自然灾害 | 地震、台风、火山、大旱、传染病 | 速报 + risk-off、日元回流、数日高波动 |
| 政治/新闻 | 选举、公投、贸易战、银行危机、原油 | 底部新闻条与新闻页 |
| 谣言 | 「据称央行正讨论…」 | 先推动价格；为假时完全回吐并发「辟谣」 |
| 要人发言 | 鹰派/鸽派/模棱两可 | 新闻 + 漂移或波动上升 |
| 散户 / SNS | FX 民时间线、あふぃちゃん博客、芽吹喊单 | SNS 页；散户一边倒 → 止损簇被猎杀 |
| 玩家/仲间 | やす子「博客煽动」 | 推动选中品种并带动散户情绪 |

新闻标题对散户比价格晚 1 tick；「电视速报」等情报能力可以提前看到。

## 4. 交易规则（`src/core/account.gd`）
- 1 枚 = 1 万通货（日经 10、黄金 10）；损益换算成日元。
- 证拠金 = 名义金额 / 杠杆；维持率 = 净值 / 证拠金。到业者告警线弹警告，到强平线从亏得最多的仓位开始强平（附加滑点）。
- **国内业者**：25 倍、无零 cut → 负余额成为「不足金」（借金）。**海外业者**：888 倍、零 cut、点差/滑点大、每幕首个交易节点送 50% 赠金。
- 订单：市价、止损 SL、止盈 TP（下单时带或事后「设」、或在图上拖线）、追踪止损（需手法）。限价/逆限价挂单 **未实现**。
- 跳空时止损按开盘价成交；报价停止期间无法成交/强平。
- 掉期：每天 07:00 换日按利差结算，周三→周四 ×3，业者抽成。

## 5. 久留美的「メンタル」（`src/core/kurumi.gd`）
- 0~100（上限可养成）。平仓亏损按占净值比例扣（最多 −30），盈利少量回复；维持率告警 −6、强平 −22、钉住撤销 −15；每天 +2（+回复加成）。
- 低于 30（可被手法/诅咒调整）→「暴走」：头像框变红，每 36~72 tick 弹出「衝動」卡：
  屈服（メンタル +10，但被迫全力ナンピン/满仓买入）或忍住（メンタル −4）。
- 归零 → 心折断，交易立即结束；肉鸽本局失败。
- 立绘表情随含み損益与状态变化，各种事件（灾害、央行、谣言、辟谣、闪崩、钉住撤销、干预、指标惊喜、芽吹喊单）有专属台词。

## 6. 肉鸽模式（`src/core/run_state.gd`，`src/run/`）
### 6.1 一局的结构
- 3 幕，每幕一张 7 层分叉地图（第 0 层起点相場、1~5 层混合、第 6 层 Boss）。
- 节点：
  - **相場**：3 个交易日；资金 +8%/10%/12%（按幕）有额外 FP。
  - **精英**：特殊规则（新闻风暴、猎杀止损、剧烈波动、流动性枯竭、超级指标周、高息货币危机），奖励 3 选 1 手法（偏优秀）。
  - **事件**：18 个文字事件，仲间登场，选项影响资金/メンタル/FP/道具/手法/诅咒/借金。
  - **商店**：用 FP 买手法与道具、回メンタル、驱除诅咒、刷新手法。
  - **休息**：便利店打工（资金 + 幕基数）/ 睡觉（メンタル +35）/ 复盘（FP +30）。
  - **Boss**：5 个交易日，特殊规则；结束时**净资产（资金−借金）**须达到本幕目标，否则失败。击败后 3 选 1 稀有手法、メンタル +30。
- 幕目标：80 万 → 400 万 → 2000 万（通关）。通关后可「结算」或进入无尽模式（每幕目标 ×4，波动递增）。
- 失败条件：Boss 未达目标、メンタル归零、普通节点结束时资金 < 1 万円。
- 节点进行中退出：读档时该节点作废，メンタル −10（防止反复读档）。
- 平衡由 `tests/sim_balance.tscn` 校准（基线见 `docs/maintenance.md` §4.8）。

### 6.2 货币
- **资金（円）**：交易本金也是分数。**借金**：年利 109.5%，每交易日复利，可在地图上还款。
- **FP**：交易节点结算（基础 15/30/50 + 收益率% 最多 25 + 达成目标 15 + 博客收入）× FP 倍率。
- **相場勘**：一局结束结算 = 8 + 节点×2 + 通过幕数×25 + log₂(最高净资产/起始)×6（通关再 +40+挑战度×10）。

### 6.3 构筑
| 系 | 思路 | 手法例 |
|---|---|---|
| 情报 | 看到隐藏信息 | 经济日历PRO、经济新闻订阅、FX民雷达、均线、布林带、RSI、止损簇探测、电视速报、望远镜、趋势水晶、白猫的直觉 |
| 风控 | 少亏、稳心态 | 止损之锚、风控手册、亏损保险、追踪止损、久留美的FX笔记、好梦枕头、降噪耳机、零cut券 |
| 赌徒 | 多赚多亏 | 火箭杠杆、赌徒骰子、黑卡、黄金K线、ナンピン定规 |
| 消息 | 事件交易 | 消息交易术、电视速报 |
| 掉期 | 吃利息 | 掉期存钱罐、复利金币（+里拉/日元、掉期特化证券） |
| 经济 | FP / 持仓数 | 第二台电脑、多屏战斗站、兔子吊坠 |

**仲间**（剧情中结识后解锁；初始 1 个位，养成可到 3）：
- 小金萌智子（ch06）：被动显示公允价、指标预感 +20%；主动「冷眼分析」1 天内显示隐藏趋势与止损簇。
- 山師芽吹（ch06）：被动「芽吹的预言」——每天在 FX 民时间线喊单，约 3/4 是反的；主动「一起去借钱」借入净值 50%（年利 109.5%）。
- 高根やす子（ch07）：被动每天 +4 FP、更不易暴走；主动「博客煽动」推动当前品种与散户情绪。

**道具**：能量饮料、便当、黑咖啡、纸巾盒、护身符、神签、有给休假、眼罩；事件限定：父亲的存折（+300 万、メンタル −30、诅咒「罪恶感」）、闇金名片。
**诅咒**：罪恶感、ポジポジ病（空仓一天 −6）、睡眠不足、滞纳的税金（节点盈利扣 20%）、强欲。
**业者**：海外FX（默认）/ 国内大手 / 掉期特化证券（养成解锁）/ 专业 ECN（养成解锁）。

### 6.4 难度曲线
- 第一幕：趋势强（trend×2.0）、regime 平均 3.5 天、灾害少；Boss「雇用统计之夜」/「日银的意外」。
- 第二幕：趋势×1.7、regime 2.8 天、谣言与猎杀止损增多；Boss「汇率干预」/「清晨的闪崩」。
- 第三幕：趋势×1.45、regime 2.2 天、高波动、灾害×1.6；Boss「黑色星期四」（EUR/CHF 钉住崩溃）/「金融危机」。
- 首通后解锁挑战度 1~10（目标 +15%×2、起始メンタル −10、点差 +20%、商店涨价、新闻更晚、猎杀更频繁、休息变少、每幕诅咒、最终目标 3000 万）。

### 6.5 局外养成「相場勘」（21 项，`data/run/meta.json`）
起始资金、メンタル上限/回复、FP 倍率、打工收入、日历天数、指标预感、道具栏、仲间位、商店折扣、免费刷新、开局手法、首次强平返还、
研究品种（EUR/CHF、TRY/JPY、日经、黄金）、开户（掉期特化、专业 ECN）、稀有情报/赌徒手法进卡池。
