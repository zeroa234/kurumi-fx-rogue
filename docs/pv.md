# 宣传 PV

成片：`output/pv/kurumi-fx-rogue-pv.mp4`（1920×1080 / 30fps / H.264 CRF16 + AAC 256k，71.4 秒，约 91 MB，不入库）。响度 −16.0 LUFS（配乐 +3.5 dB，限幅 0.75）。
全部可复现：实机画面由 Godot Movie Maker 录制，合成由脚本按剪辑表逐帧渲染。

**v2（当前）**：全片统一成游戏的像素规格；演出改成二次元手游 PV 的常见手法，镜头切在拍点上。
v1（高清插画 + 大量推拉平移，PV 时长 71.5 秒）的脚本与剪辑表在提交 `1f73700`。

## 1. 像素规格（v2 的核心约定）
- 合成画布 **640×360**（游戏原生分辨率），成片最近邻放大 **3 倍**——每个画布像素都是 3×3 的方块，没有插值出来的模糊像素。
- 实机录像原生 640×360 直接贴；背景/CG 320×180、立绘 128×128 以 **2 倍** 贴（与游戏内显示一致）；推近只用整数倍（×2/×3/×5）。
- 关键帧插画也按游戏背景同一算法像素化（320×180 / 48 色）：`assets/pv/px/`，并把久留美拆成角色层 `*_fg` 与背景层 `*_bg`（AI 蒙版，角色区域补色），用来做视差和「标题压在角色身后」。
- 位移取整到画布像素；所有半透明（淡入淡出、闪白、暗角、渐变、残影）都用 4×4 Bayer 抖动，不做 alpha 混合。
- 像素字 Fusion Pixel 12px，整数倍放大（字幕 1 倍＝成片 36px）。

## 3. 文件
| 路径 | 内容 |
|---|---|
| `scripts/pv/build_edit.py` | **剪辑脚本**：用 Python 写镜头（复用功能段标题、仲间面板等结构），生成 `config/pv-edit.json`。改剪辑改这里 |
| `config/pv-edit.json` | 剪辑表（生成物，入库；字段说明在 `_doc`）：镜头、图层、转场、特效、音效时间点、配乐偏移 |
| `scripts/pv/make_pv.py` | 合成器：640×360 画布逐帧合成（Pillow）→ ×3 最近邻 → ffmpeg；图层类型/转场/特效见 `_doc` |
| `scripts/pv/prep_pv_pixels.py` | 关键帧像素化 + 角色/背景分层 → `assets/pv/px/`（抠图复用 `gen_assets.py` 的 AI 蒙版，缓存 `output/masks/`） |
| `scripts/pv/pv_capture.gd` + `.tscn` | 录制驱动：`-- --clip=<名字>` 打开对应场景，替玩家关弹窗、调速度、下单、翻对话 |
| `scripts/pv/capture_all.sh` | 逐个片段跑 Movie Maker → `output/pv/raw/<片段>/f########.png`（640×360），录前备份存档、结束还原 |
| `scripts/pv/music_probe.py` / `strip_vocals.py` | 配乐旁证（人声识别、能量、节拍）/ demucs 去人声 |
| `assets/pv/` | 高清关键帧 `pv_resolve / pv_key / pv_rain.png`、配乐 `pv_theme.ogg`（来源在 `index.json`）；`px/` 像素版与分层。有 `.gdignore`，不会被导入或打进游戏包 |

## 4. 重新出片
```bash
cd projects/kurumi-fx-rogue
bash scripts/pv/capture_all.sh                     # 录全部实机片段（约 1 分钟；会弹出游戏窗口）
python scripts/pv/prep_pv_pixels.py                # 关键帧像素化与分层（素材有变化时；有蒙版缓存则不连 ComfyUI）
python scripts/pv/build_edit.py                    # 生成剪辑表
python scripts/pv/make_pv.py --sheet 6,24,50,62    # 几个时刻拼一张总览 → output/pv/sheet.png（单帧用 --stills）
python scripts/pv/make_pv.py --preview             # 1280×720 快速预览 → output/pv/preview.mp4
python scripts/pv/make_pv.py                       # 成片（约 1 分钟）
```
- 只改字幕/时长/演出：改 `build_edit.py` → 重新生成剪辑表 → 合成，不必重录。
- 改了游戏界面或素材：重录对应片段（`capture_all.sh trade snb`），再核对剪辑里的 `from` 帧号与 `punch` 推近中心（行情是固定种子，界面不变时帧号稳定）。
- `prep_pv_pixels.py` 需要 `output/hires/cg_win.png`、`cg_shock.png`（`gen_assets.py` 产出，不入库）；换机器先跑 `python scripts/gen_assets.py`。产物 `assets/pv/px/` 已入库，素材不变就不用重跑。
- 片段名与录制秒数在 `capture_all.sh` 的 `ALL=`；驱动里还保留了 `hub`、`codex`（本机存档进度低，画面多为锁定/有进行中的局，没有用）。

## 6. 素材来源与已知问题
- **关键帧**：ComfyUI `anima-t2i` + `kurumi.safetensors`（与游戏立绘同一 LoRA），见 `assets/pv/index.json`。像素版用游戏背景同一算法；角色层用 BiRefNet_toonout 蒙版。
  cg_win 的蒙版把楼群和钞票也当成前景，所以不拆层（只用整图）。pv_key 背景层里角色位置是补出来的色块，只在角色平移几像素时露出边缘。
- **立绘/图标/Q 版/背景**：直接用游戏里的 `assets/sprites/`（2026-10-07 AI 抠图返工后的版本），实机片段也已在返工后重录。
- **配乐**：YuE2 本地生成，demucs 去人声（详见 `assets/pv/index.json`）。**没有经过人耳试听**——去人声可能留下轻微的「挖空」感，正式发布前请听一遍。
  原曲在 token 上限处截断、没有自然收尾，片尾 64.5~67 秒淡出，最后 4.5 秒只有片尾音效。
- **音效**：游戏自己的 `assets/sfx/*.wav`（v2 新增：角色登场 `open`、仲间面板 `click`）。**字体**：Fusion Pixel（OFL）。
- 抖动与硬边像素让 H.264 码率变高（CRF16 约 10 Mbps，v1 约 4.5 Mbps）；要压体积可把 `make_pv.py` 里的 CRF 调到 18~20。
- 合成只依赖 Pillow + ffmpeg（不需要 numpy）。
